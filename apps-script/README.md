# 後端設定（Google 試算表 + Apps Script）

這一層做兩件事：存訓練資料、代理中央氣象署 API。

**為什麼要代理氣象 API：**GitHub Pages 上的網頁原始碼是公開的，任何寫在前端的金鑰等於公開發布。把氣象請求繞過 Apps Script，金鑰就只存在 Google 這端，網頁本身沒有任何秘密。

全部步驟約 10 分鐘，只需要做一次。

---

## 1. 建立試算表

1. 開 [sheets.new](https://sheets.new) 建一份新的 Google 試算表
2. 命名為 `富士山訓練資料`（名字隨意）

三個工作表 `runs` / `done` / `meta` 會在第一次執行時**自動建立**，不用手動開。

## 2. 貼上程式碼

1. 在試算表選單列選 **擴充功能 → Apps Script**
2. 把預設的 `Code.gs` 內容整個刪掉
3. 貼上本資料夾的 [`Code.gs`](Code.gs)
4. 按 💾 儲存

## 3. 放入氣象署金鑰

金鑰不寫在程式碼裡，改放「指令碼屬性」：

1. Apps Script 編輯器左側點 ⚙️ **專案設定**
2. 捲到最下面 **指令碼屬性 → 新增指令碼屬性**
3. 屬性填 `CWA_KEY`，值填你的金鑰（`CWA-` 開頭那一串）
4. 儲存

> 金鑰可在 [氣象署開放資料平臺](https://opendata.cwa.gov.tw/) 會員專區查看或重新產生。

## 4. 自我檢查

回到編輯器，函式下拉選 **`selfTest`** → 按 **執行**。

第一次會跳授權：選你的 Google 帳號 →「進階」→「前往（不安全）」→ 允許。這是在授權**你自己寫的**指令碼存取你自己的試算表，正常流程。

執行記錄應該出現類似：

```
CWA_KEY 已設定：是
工作表 runs：就緒
工作表 done：就緒
工作表 meta：就緒
氣象取得成功：未來 14 個時段、逐時 56 點
目前資料：0 筆跑步、0 個已完成課表
```

任何一行是「否」或「失敗」，先解決再往下走。

## 5. 部署成網頁應用程式

1. 右上 **部署 → 新增部署作業**
2. 齒輪選 **網頁應用程式**
3. 設定：
   - 說明：`fuji-v1`（隨意）
   - 執行身分：**我**
   - 誰可以存取：**任何人**
4. 按 **部署**，複製那串 **網頁應用程式網址**（`https://script.google.com/macros/s/AKfycb.../exec`）

> **「任何人」代表什麼：**拿到這個網址的人可以讀寫這份訓練資料。網址本身很長且不可猜測，等於一把鑰匙 —— 別公開貼出來。裡面只有跑步距離跟日期，外洩的後果有限，但也沒必要讓人看。真的外流就重新部署一次換網址。

## 6. 接上前端

把網址填進 `config.js` —— 它在**上一層資料夾**，也就是 `web/config.js`
（完整路徑：`D:\馬拉松規劃\web\config.js`）。

只改 `gasUrl` 那一行，結尾逗號要留著：

```js
window.FUJI_CONFIG = {
  gasUrl: "https://script.google.com/macros/s/AKfycb...../exec",
  cwaKeyForLocalFileOnly: ""
};
```

重新整理網站，右上角的同步標籤應該從「未連線」變成「已同步」。

---

## 之後改了 Code.gs 怎麼辦

Apps Script 的網頁應用程式**不會**自動套用新程式碼。改完要：

**部署 → 管理部署作業 → ✏️ 編輯 → 版本選「新版本」→ 部署**

用這個方式網址不會變。若選「新增部署作業」會產生**新網址**，就得回頭改 `config.js`。

---

## 疑難排解

| 症狀 | 原因與處置 |
|---|---|
| 同步標籤一直是「連線失敗」 | 多半是部署時「誰可以存取」沒選「任何人」。回到管理部署作業改掉 |
| 天氣區塊說後端沒回傳資料 | `CWA_KEY` 沒設或打錯。跑一次 `selfTest` 看訊息 |
| 改了 Code.gs 但行為沒變 | 忘記重新部署新版本（見上一節） |
| 資料沒進試算表 | 打開試算表看 `runs` 工作表是否被手動改名或刪掉 |
| 想清空重來 | 直接在試算表刪掉 `runs` / `done` / `meta` 三個工作表，下次呼叫會自動重建 |

## 資料長什麼樣

| 工作表 | 欄位 | 說明 |
|---|---|---|
| `runs` | id, date, km, sec, type, note, created | 每一次跑步；`sec` 是總秒數，配速由前端算 |
| `done` | key, value, updated | 已完成的課表，key 形如 `5.2`＝第 5 週第 3 次 |
| `meta` | key, value, updated | 目前只有 `branch`＝`half`（17K）或 `full`（全馬） |

可以直接在試算表裡手改，前端下次載入就會讀到。
